## 新增功能

- 支持 Kimi Code、DeepSeek 和 OpenCode Go 多账号管理，提供本地统一网关与负载均衡。
- 支持 Chat Completions、Responses 和 Anthropic Messages 协议转换，包括流式响应和工具调用。
- 增加用量统计、模型价格、额度估算与每日模型性能视图，支持调整账号卡片顺序。
- 增加 App 内版本检测、后台下载、重启安装和 macOS 旧版备份。
- 提供桌面界面与深浅主题切换。

## 问题修复

- 修复协议转换中的工具调用配对及流式响应边界问题。
