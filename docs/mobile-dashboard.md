# 响应式额度仪表盘预览

运行 `npm run dev:mobile`，打开 `http://127.0.0.1:5180/mobile.html`。
运行 `npm run build:mobile`，静态产物位于 `out/mobile/`。

这是使用示例数据的交互原型，独立于 Electron 桌面入口。账号额度、余额复用
`src/shared/contracts.ts` 中的数据结构；尚未连接本地实时服务或 Cloudflare Tunnel。

支持账号供应商筛选、账号详情、5 小时／周／月额度、按币种余额、重置倒计时、
用量趋势、深浅色主题，以及连接中断／恢复的状态演示。每 30 秒刷新的是演示时间戳，
不会向上游请求真实额度。所有页面均标注示例数据。

## 响应式规则

| 场景                                                  | 布局                                               |
| ----------------------------------------------------- | -------------------------------------------------- |
| 手机竖屏（小于 700px）                                | 单列卡片、底部导航、详情上下布局                   |
| 手机横屏（横向、高度不超过 540px、宽度不超过 1024px） | 双列卡片、紧凑顶部导航、详情左右布局、刘海安全边距 |
| 平板竖屏                                              | 双列卡片、顶部导航、详情左右布局                   |
| 平板横屏（900–1199px，高度至少 600px）                | 三列卡片，详情主次栏比例调整                       |
| 桌面                                                  | 三列卡片，1500px 起四列；顶部导航                  |

布局根据可用视口适配，旋转设备不会重置筛选、当前页面或主题。

## 验证

启动预览服务后执行 `node scripts/mobile-smoke.mjs`。脚本检查手机、平板的横竖屏、
桌面尺寸、所有页面横向溢出、卡片列数、导航位置，以及筛选、详情、主题和断线交互。
截图输出到 `artifacts/mobile/`。
